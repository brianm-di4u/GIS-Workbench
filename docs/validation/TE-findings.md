# T&E findings register

One row per finding raised by the T&E campaign (see [TE-master-plan.md](TE-master-plan.md) §6). A finding is closed only by a passing re-test whose title carries the TE id.

**Severity**
- **S1:** crash, hang, wrong geolocation or measurement, data loss, security or marking failure.
- **S2:** a function fails or gives a wrong result with a workaround.
- **S3:** degraded, slow, or confusing behaviour.
- **S4:** cosmetic.
- **IMP:** improvement; tracked in [TE-improvements.md](TE-improvements.md).

**Status** moves Open → Root-caused → Fixed → Verified, or ends as Accepted (owner) or Not-a-defect (oracle or test error).
